What the notification can and can't do
Review opens Cleanup Review in agent request mode, scrolled to the plan. No Approve or Deny button. Approving needs the full plan on screen, every item reviewed and the typed code. Posted by scull itself, never by the MCP client, so the agent can't write to this channel or change its wording. Later keeps the request in the menu bar widget until it expires. Do Not Disturb is respected; the 15-minute clock still runs. scull not running? The agent is told to ask you to run scull approve 9c41e07b in your own terminal.
